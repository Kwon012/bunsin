# 분신 키우기 — Phaser PoC

Phaser 3 + Vite + TypeScript. push하면 GitHub Actions가 테스트·빌드 후 GitHub Pages로 배포한다(`dist/index.html` 단일 파일, 외부 의존 없음).

- 플레이: https://kwon012.github.io/bunsin/
- 디버그: 주소 뒤 `?debug=1`(DBG 버튼) 또는 화면 왼쪽 위 모서리 3번 탭 → 배속 ×1·×10·×60·×600, 오프라인 1h/8h/30일, 돈 ×10/×1000, 월급날 즉시, 매니저/통장 해금, 시각 23시, 하루 지남, 도시+1 준비, 지표 JSON, 세이브 초기화
- 규칙: [CLAUDE.md](CLAUDE.md) · 기획서: [docs/bunsin-gdd.md](docs/bunsin-gdd.md) · 가정: [ASSUMPTIONS.md](ASSUMPTIONS.md) · 콘텐츠 CSV 열: [docs/content-csv.md](docs/content-csv.md)
