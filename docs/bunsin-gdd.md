## 1. 개요

- **한 줄:** 분신을 고용해서 돈 버는 모바일 방치형 게임. "나 하나로 부족하면, 나를 늘린다."
- **가제:** 『분신 키우기: 나 1000명이 출근합니다』
- **장르·플랫폼:** 세로 한 손 방치형(키우기) · Unity 2D · Android 먼저
- **유저가 하는 일(4가지뿐):** 고용(주 행동) · 응원(탭) · 수령(정산서·월급날) · 확장(도시 이사)
- **재미 공식:** 만지면 터지고, 기다리면 터지고, 쌓이면 보이고, 정들면 못 떠난다
- **재미 기둥:** 손맛 · 기대 · 성장 · 애착
- **현실 경제 요소:** 시급·월급날·자격증·사업·배당·건물주. '계산'이 아니라 '정서'로만 넣는다.

### 1.1 목표와 타깃

게임의 목표는 신규 유저가 재밌다고 느껴 충성 유저가 되는 것이다. 충성 신호는 "이 게임"이 아니라 "내 분신 마을"이라고 부르기 시작하는 순간이다.

| 타깃 | 플레이 모습 | 이 게임이 주는 것 |
|---|---|---|
| 라이트 유저 | 출퇴근 5~10분, 한 손, 생각하기 싫음 | 생각 없이 고용·수령, 기분 좋은 마무리 |
| 하드 유저 | 저녁 1~4시간, 최적화·수집 | 자격증 선택, 숨은 조건 개성 분신, 도시별 효율 |
| 숏폼 유입 신규 | 광고에서 본 '나로 가득 찬 화면'을 기대 | 1분 안에 마을 공개 줌아웃 |
| 비게이머 | 게임을 거의 안 함 | 텍스트 튜토리얼 없이 손가락 가이드 하나 |

### 1.2 설계 원칙 (바꾸려면 사용자 결정)

1. 확률 상품 없음. 개성 분신도 비확률로만 얻는다.
2. 손해 없음. 파산·손실·초기화 벌칙이 없고, 놓친 보상은 쌓였다가 받는다.
3. 고민 3단계. 몰라도 진행이 막히지 않고, 고민은 하고 싶은 사람만.
4. 새 화면·새 화폐를 늘리지 않는다. 새 요소는 기존 요소를 배가할 때만.
5. 강제 전면 광고 없음. 광고는 유저가 골라서 보는 보상형만.
6. 분신 합체(머지) 없음.
7. 실존 인물·브랜드·종목은 패러디로만.
8. 하루 필수 플레이는 5분 이내. 출근 도장·정산서 수령 같은 필수 요소는 5분 안에 끝나고 그 이상은 모두 선택(R-002).

### 1.3 세계관과 톤

월세가 밀린 20대 청년 '나'가 알바 세 개를 뛰다 쓰러진 날, 거울 속의 내가 걸어 나온다. 돈을 내면 분신이 하나씩 늘어나고, 분신들은 언덕 아래 골목 편의점에서 시작해 꼭대기 펜트하우스까지 출세한다.

- **톤:** 거지 키우기식 병맛 + 가벼운 현실 풍자. 조롱이 아니라 응원하는 톤.
- **웃음 포인트:** 같은 얼굴 수천 명, 분신이 본체보다 먼저 승진, 분신끼리 회식, 엄마 문자("아들 출세했네"), 뉴스 "도시에 똑같은 얼굴 1만 명".
- **출세 서사:** 본체의 자리가 반지하 → 편의점 카운터 → 사무실 책상 → 사장실 → 펜트하우스.
- **도시:** 우리 동네 → 부산 → 여의도 → 도쿄 → 상하이 → 두바이 → 실리콘밸리 → 뉴욕, 8개(R-011).
- **레퍼런스:** 거지 키우기(병맛 만화 카드, 확장 순서), 대건물주(건물주 판타지), 알바왕 키우기(앱명 확인 필요).

## 2. 게임 시스템

### 2.1 핵심 루프

한 도시 안에서는 **고용 → 일 → 정산**이 생각 없이 돌고, 성장이 벽에 닿으면 버튼 하나로 다음 도시로 이사해 더 빠르게 다시 시작한다.

1. **고용:** 돈을 내면 분신이 그 직종에 생긴다(고용 = 배치).
2. **일:** 분신이 초당 수입을 번다. 본체를 탭하면 직접 벌고, 연타하면 피버로 전원이 빨라진다.
3. **정산:** 30분마다 월급날 보너스, 접속하지 않은 동안에도 일부가 쌓인다.
4. **다시 고용:** 번 돈으로 분신이나 자격증을 산다. 팀 보너스와 자격증이 성장을 계단처럼 끌어올린다.
5. **도시 확장:** 그 도시의 꼭대기 직종을 고용하면 이삿짐 트럭이 열리고, 다음 고용까지 3분 넘게 걸리는 벽에 닿으면 추천된다. 명성과 개성 분신을 들고 다음 도시로.

### 2.2 페이싱 목표 (누적 플레이 시간 기준, 시뮬레이션은 임시 수치)

| 순간 | 목표 | 시뮬레이션 결과(중앙값, v3.5) |
|---|---|---|
| 첫 분신 | 10초 안 | 약 9초 |
| 마을 공개 | 1~3분 | 0.7분 |
| 첫 월급날 | 첫 세션 안 | 4분 |
| 사무실(직장) 해금 | 첫날 | 10분 |
| 매니저 해금 | 2일 차 | 80분 |
| 가게(사업) 해금 | 3일 차 | 20분(목표보다 이름, 남은 과제) |
| 첫 도시 확장 | 3~4일 차 | 157분(지훈 기준 2일 차 끝) |
| 7일간 도시 수 | 2~4개(제안) | 1~7개(중앙값 5) |
| 벽 노출(R-015) | 페르소나 중앙값 35% 이하(가정) | 재측정 52% → **미달** |
| 세션 최장 막다른 벽(R-015) | 10분 이하(가정) | 재측정 라이트 11분·미드 14분·하드 60분 → **모두 미달** |
| 귀환 벽(R-015) | 0% | 0% → 달성 |
| 배당 비중(R-015) | 15% 이하(가정) | 통장을 안 깨는 유저 43~49%(통장 토의는 6% 이하, 해석 대조 전) → **미달** |

- v3.6 경제(R-005~R-008) 시뮬레이션: 첫 이사 2~3일 차, 7일간 도시 3~4개, 가게 첫 고용 2~3일 차, 최장 벽 6~34분(시스템부 경제 정비 토의, 2026-11-01).
- 도시별 경제(R-011~R-014) 시뮬레이션(미드, 하루 90분): 이사 시점 3.0 · 4.6 · 7.0 · 11.0 · 14.2 · 18.2 · 23.0 · 28.2일 차(라이트 4.5~41일, 하드 2.2~20일). 도시 끝 총 자산은 매번 크게 늘어남(동네 1.02조 → 부산 157경 → … → 뉴욕 2,427불가사의).
- **벽(R-015, 2026-11-01 확정):** 접속 중 다음 진전까지 180초 이상 남고(월급날 보너스 포함, 통장으로 살 수 있으면 제외) 의미 있는 행동이 없는 상태. 꼭대기 직종 첫 고용 전 = 막다른 벽, 후 = 출구 있는 벽(이사 가능). 위 목표는 가정이며 실제 테스트로 검증한다. **현재 경제는 3개 지표가 목표 미달이고 경제 수치는 아직 바꾸지 않았다**(후속: 업무 #4·#5).

### 2.3 성장

성장은 '분신 추가'와 '배수 구매' 두 가지로만 이뤄진다. 모든 구매는 하단 고용 시트 한 곳에서 하고, 추천 버튼이 가장 효율 좋은 것을 표시한다.

| 요소 | 규칙 | 연출·피드백 |
|---|---|---|
| 고용 | 돈을 내면 분신 +1. 직종별 버튼. ×1·×10·최대 일괄 고용. 고용가는 지수로 증가하며 높은 칸일수록 가파름. **고용 인원 상한 없음**(v3.6). 증가율: 도시 1은 칸별 1.07~1.11(5칸), 도시 2~8은 1.07 + 0.005 × (칸 − 1)(R-014) | 거울에서 '뿅'. ×10은 단체 점프. 100번째·1000번째는 왕관 쓴 기념 분신 |
| 직종 사다리 | 도시 8개, 직종 58종, 도시별 칸 수 5·6·7·8·8·8·8·8(R-011). 칸 계층은 1~3 알바, 4 직장, 5~6 사업, 7~8 투자로 모든 도시 공통. 다음 칸은 이전 칸 25명에서 해금, **8칸만 7칸 10명에서 해금**(v3.6). 칸 가격·수입은 도시마다 다름(R-014) | 해금 때 출세 만화 컷 + 본체 비포·애프터 카드 |
| 직종 성격 | 모든 직종이 초당 수입. 알바는 초당 위주, 직장은 월급날 보너스 위주로 비중이 다름 | 추천 버튼이 계산하므로 몰라도 손해 없음 |
| 팀 보너스 | 직종별 25·50·100·150명…1,000명마다 그 직종 수입 ×2(v3.6: 1,000명까지 연장) | 단체 사진 자동 촬영 → 추억 앨범. 일부 단계는 개성 분신을 주는 '특별 팀 보너스' |
| 자격증 | 직종별 25·50·100·150·250·400명에서 열리는 1회성 구매, 그 직종 수입 ×3. 고용 시트 안 같은 줄, 추천 버튼이 분신 고용과 비교 | 자격증 취득 컷(예: 편의점 분신이 바코드 자격증) |
| 매니저 분신 | 접속 중 월급날 4회째에 무료 해금(유료는 조기 해금). 자동 고용·자동 응원. **이사 후에도 유지**(R-008) | 은퇴식: 본체가 손을 놓고 커피. 이후에도 직접 탭이 빠르면 '직접 탭 = 더 빠름' 표시 |

### 2.4 수입

돈은 네 갈래로 들어온다: 탭, 초당 수입, 월급날, 오프라인 정산.

| 요소 | 규칙 | 연출·피드백 |
|---|---|---|
| 탭 | 본체 탭 1회 = 기본값 + 초당 수입의 12%. 꾹 누르기 = 느린 자동 탭 | 일하는 표정, 동전 튀김 |
| 응원 피버 | 연타로 게이지 충전(꾹 누르기는 느리게 충전) → 15초간 분신 전원 수입 ×3 | 3단계 색 변화, 본체가 확성기, 마을 분신이 구호를 따라 외침. 끝나면 '오늘 최고 콤보' 한 줄 |
| 초당 수입 | 모든 직종이 초당 수입을 번다. 고용 즉시 오름 | 상단 바의 초당 수입이 바로 오름 |
| 월급날 | 모든 직종 공통 하나, 30분마다(첫 세션 4분). 보너스 = 지난 월급날 이후 번 돈에 비례(직종 몫: 알바 5%·직장 60%·사업 30%·투자 30%), 최소 초당 수입 120초치 | 10초 전 카운트다운 → 분신 전원 월급봉투 환호. 명세서: 알바 주휴수당 · 직장 월급 상여 · 사업 결산 보너스 · 투자 운용 수익 · 배당주 통장 배당금, 개그 공제 항목("본체 간식비") |
| 밀린 월급봉투 | 접속하지 않는 동안 지난 월급날 보너스는 사라지지 않고 쌓임 | 정산서와 귀가 행렬에서 받음 |
| 오프라인 수입 | 투자 직종 100%, 나머지 직종 25%('분신 야간 근무'). 상한 8시간(28,800초), 이후에도 25% 속도로 계속 | 정산서 |
| 배당주 통장 | 매니저 해금 **다음 월급날** 개설(축하금 = 초당 수입 × 600초). 접속 중 초당 수입의 10% 자동 적립(끌 수 있음)·직접 입금 가능. 월급날마다 잔액 10% 배당, 한도 = 초당 수입 × 7,200초까지 재투자, 넘치면 현금. 가격 변동 없음. 언제든 깨기 가능, 벽(다음 구매 3분 초과)에서 '통장 깨서 지금 사기' 버튼. **이사해도 유지(R-013):** 지금 종목은 '보유 종목'이 되어 월급날마다 잔액 10% 현금 배당(합계 상한 = 지금 초당 수입 × 360초), 언제든 매도 가능(깨기 순서: 지금 종목 → 보유 종목). 새 도시 종목이 열리고 자동 적립·직접 입금은 지금 종목에만 | 상단 바 돼지 저금통 게이지, 명세서 '배당금' 줄, 저금통 깨기 2초 연출. 화면 문구에 '복리·재투자' 대신 '넣어 두면 월급날마다 불어나요' |

### 2.5 진행

다음 목표는 항상 하나만, 90초 안에 닿는 것을 보여준다. 큰 진행은 마을 공개와 도시 확장 두 번의 절정으로 나뉜다.

| 요소 | 규칙 | 연출·피드백 |
|---|---|---|
| 목표 바 | 목표는 하나. 항상 90초 안에 닿는 가장 가까운 목표. 새 목표는 일부(10~20%) 채운 채 시작. 결제 유도에는 쓰지 않음(R-003) | '3명 남음'처럼 남은 양 표시, 다음 구매까지 남은 시간 표시, 자금이 절반 찼을 때 작은 연출 |
| 잠긴 구역 미리보기 | 처음부터 홈 창문 너머로 그 도시 꼭대기 건물 실루엣이 보임(동네: 언덕 위 분식집 본점 → … → 뉴욕: 맨해튼 펜트하우스, R-011) | 잠긴 구역은 흐리게 |
| 마을 공개 | 분신이 홈에 가득 차는 순간(임시 15명) 자동 줌아웃 → 마을 탭 해금. 공개 전 고용가는 아주 낮게 | 창밖으로 카메라가 빠지며 언덕 전체 공개, 분신들이 골목 편의점으로 뛰어감. 직후 첫 단체 사진 + 공유 제안 1회 |
| 도시 확장 | 꼭대기 이삿짐 트럭. 이사 조건은 **8개 도시 모두 '그 도시 꼭대기 직종(★) 첫 고용'**(R-012). 추천은 '다음 고용까지 3분 이상'인 벽에서만, 이사는 선택. 이사하면 돈·분신·자격증은 초기화, 명성(영구 배수)과 **정착금**(새 도시 1칸 첫 분신 3명치)을 얻음. 새 도시 1칸 첫 분신은 이전 도시 꼭대기 첫 분신보다 10배 비싸고 수입은 수백~천여 배(R-014). 매니저·배당주 통장은 유지(R-008·R-013) | 확장 화면에 얻는 것(×N, 남는 개성 분신)을 크게, 초기화되는 것을 작게. 이삿짐 트럭에 분신들이 우르르 |
| 이사 후 보존 | 떠난 마을은 추억 앨범에 그대로 보존. 개성 분신은 전원 동행. 새 도시는 '이사 축하'로 첫 목표 일부를 채운 채 시작 | 새 도시 첫 화면부터 개성 분신이 보임 |
| 도시 규칙 한 줄 | 도시마다 규칙 하나를 살짝 비틂(예: 월급날이 더 자주 오는 도시, 배당 보너스 도시) | 트럭 화면에 한 줄로 표시 |

### 2.6 이벤트·발견

고용과 고용 사이의 빈 시간을 채운다(시뮬레이션에서 무반응 시간을 28.9% → 11.1%로 줄인 핵심).

| 요소 | 규칙 | 연출·피드백 |
|---|---|---|
| 사건 카드 | 말풍선을 단 분신이 마을과 홈 창문에 나타남. **동적 등장:** 12초 넘게 아무 일이 없으면 바로 등장(최소 간격 30초, 세션 첫 3분은 20초). 절반은 한 번 탭으로 받는 카드, 절반은 손해 없는 2지선다. 선택이 다음 사건으로 이어지는 연작, 같은 사건은 일정 간격 안에 다시 안 나옴 | 결과 즉시. 연작 진행 표시 |
| 개성 분신 | 비확률. 행동 기반 숨은 조건으로 획득(밤 11시 접속 → 야근왕, 피버 연속 → 확성기 분신, 첫 월급날, 팀 보너스 25명, 분신 100명). 첫 1명은 누구나 얻게 설계. 건물당 1칸 배치, 새로 얻으면 자동 추천 배치. 작은 패시브 효과. 개성 분신만 이름 변경 가능 | 도감에 실루엣 + 2단계 힌트(하루가 지나거나 다른 개성 분신을 얻으면 구체화). 같은 얼굴 + 특징 소품 |
| 숨은 장면 | 도시마다 6개를 새로 배치(골목 고양이, 분신끼리 연애 등). 마을을 구경하면 발견 | 앨범에 기록, '이 도시 숨은 장면 2/6' 카운터 |

| 마을 뉴스 | 마을 상단 한 줄, 60초마다. 200줄 + 방금 일어난 일과 연동("분신 #128이 승진했다") | 탭하면 공유 카드 |

## 3. 경제 공식과 데이터 (v0.2)

**모든 경제 수치는 구조 검증용 임시값이다. 실제 테스트 후 조정한다.** 게임과 시뮬레이터가 같은 CSV를 읽는다.

### 3.1 데이터 파일

기준 위치는 Claude 프로젝트 문서 `data/economy_v0.2/`다(v0.1은 `data/economy_v0.1/`에 보관). Unity 쪽 저장 위치는 개발부가 정한다.

| 파일 | 내용 |
|---|---|
| `cities.csv` | 도시 8줄: id·이름·테마·칸 수(slots)·move_slot/move_count·first_cost(1칸 첫 분신 가격)·first_income·settle_first_clones/settle_money(정착금)·cost_step·income_step·growth_base·growth_step·fame_unit(명성 단위)·tap_base·stock_id/stock_name_placeholder·top_building |
| `jobs.csv` | 직종 58줄: city·slot·id·name·tier(alba/job/biz/inv)·tier_label·base_cost·cost_growth·income_per_sec·unlock_prev_count·payday_share·offline_rate·payday_line·is_top |
| `economy.csv` | 전역 상수 key/value/unit/note (탭, 피버, 월급날, 오프라인, 매니저, 명성, 사건·뉴스 주기 등) |
| `account.csv` | 배당주 통장 규칙 key/value/unit/note |
| `milestones.csv` | 팀 보너스(25…1000, ×2) 16단계, 자격증(25·50·100·150·250·400, ×3) 6단계 |

- 큰 수는 유효숫자 3자리 반올림(E 표기). 파일은 UTF-8 BOM, 줄바꿈 CRLF.
- 생성식은 시뮬레이터 패키지 `tools/gen_v02.py`, 일관성 검사는 `econ/data.py validate`(시뮬레이터 패키지 안, 이 대화에서 bunsin_econ.zip으로 전달).
- `economy.csv`의 `fame_base`·`fame_city_mult`는 v0.2에서 쓰지 않는다(도시별 `fame_unit`으로 대체, R-014).

### 3.2 공식

| 항목 | 규칙 |
|---|---|
| 고용가 | `base_cost × cost_growth^보유수` (직종별). 고용 인원 상한 없음 |
| 증가율 | 도시 1: 칸별 jobs.csv 값(1.07·1.08·1.09·1.10·1.11). 도시 2~8: `1.07 + 0.005 × (칸 − 1)` |
| 도시 2~8 가격 | 1칸 첫 분신 = 이전 도시 꼭대기 첫 분신 × 10. 칸 사이 가격 ×12, 수입 ×6. 도시 1 칸 사이 가격 ×150, 수입 ×9 |
| 다음 칸 해금 | 이전 칸 25명(`unlock_prev_count`가 우선), 8칸만 7칸 10명 |
| 탭 | `tap_base + 초당 수입 × 0.12`. `tap_base`는 도시별(= 그 도시 1칸 수입) |
| 팀 보너스 | 25·50·100·150·200·250·300·350·400·450·500·600·700·800·900·1,000명에서 그 직종 수입 ×2 |
| 자격증 | 25·50·100·150·250·400명에서 열림, ×3, 가격 = `(해당 인원 + 10)명째 고용가 × 4` |
| 피버 | 15초, 전원 수입 ×3 |
| 월급날 | 첫 세션 240초, 이후 1800초 주기. 직종 몫(`payday_share`): 알바 0.05·직장 0.6·사업 0.3·투자 0.3. 최소 초당 수입 × 120초 |
| 오프라인 | `offline_rate`: 알바·직장·사업 0.25, 투자 1.0. 상한 28,800초, 이후 0.25 속도 |
| 매니저 | 접속 중 월급날 4회째 해금(`manager_unlock_paydays=4`). 이사 후 유지 |
| 명성 | `floor(√(그 도시 누적 수입 ÷ fame_unit))`, 명성 1당 수입 +20%(더하기). `fame_unit = 2,500만 × (1칸 첫 분신 가격 ÷ 10)` |
| 이사 | 조건 = 그 도시 꼭대기 직종(`is_top=1`) 첫 고용. 추천 = 다음 추천 구매까지 180초 이상(`move_recommend_eta_sec`). 정착금 = 새 도시 1칸 첫 분신 × 3(`settle_money`) |
| 이사 시 초기화/유지 | 초기화: 돈·분신·자격증. 유지: 명성, 매니저, 배당주 통장(종목은 '보유 종목'으로), 개성 분신 |
| 마을 공개 | 분신 15명(`village_reveal_clones`) |
| 사건·뉴스 | 무반응 12초 후 사건 말풍선, 최소 간격 30초(첫 3분 20초), 뉴스 60초, 숨은 장면 도시당 6개 |

### 3.4 구현 전에 확인할 것 (가정·미확정)

- 명성 배수가 팀 보너스·자격증 배수와 어떻게 곱·합으로 합쳐지는지는 이 파일에 정의가 없다. 시뮬레이터 `econ/` 코드와 대조한 뒤 구현한다.
- 통장 오프라인 배당(`offline_dividend_full_paydays`)이 배당 비중 초과의 원인 후보다. 업무 보드 #4에서 해석을 대조 중이므로 통장 구현은 그 결과 후에 확정한다.
- `data/economy_v0.2/`는 이 대화의 이전 세션에서 만든 파일이다. 아티팩트 쪽 미리보기와 다를 수 있으므로 CSV 원문이 맞다.

## 4. 화면·UX

세로 한 손 화면 두 개(홈, 언덕 마을)를 줌 전환으로 잇고, 고용 시트와 하단 탭은 두 화면이 공유한다.

### 4.1 하단 탭 4개

| 화면 | 위 → 아래 구성 | 주 행동 | 빈도 |
|---|---|---|---|
| 홈(본체) | 상단 바(보유 금액·초당 수입) → 목표 바 → 본체 + 거울 + 창문 너머 마을 → 피버 게이지 → 고용 시트(접힘 1줄) | 탭, 꾹 누르기, 추천 고용 | 매 세션 |
| 마을 | 상단 바 + 뉴스 한 줄 + 사진 모드 → 언덕 마을(세로 스크롤, 오른쪽 구역 점프 바) → 꼭대기 이삿짐 트럭 → 고용 시트 | 구경, 건물 탭, 분신 탭, 말풍선 | 매 세션 |
| 분신 | 전체 분신 수 → 직종별 인원·다음 팀 보너스 → 개성 분신 도감(도시별, 실루엣 + 힌트) → 추억 앨범 | 수집 확인, 개성 분신 배치 | 가끔 |
| 상점 | 보상형 광고(남은 횟수) → 광고 제거 → 스타터팩 → 시간 가속권 → 코스메틱 | 구매(모두 내용 확정, 확률 없음) | 가끔 |

### 4.2 탭이 아닌 팝업

| 팝업 | 뜨는 때 | 구성 |
|---|---|---|
| 정산서 | 앱 복귀 | §2.7 참고 |
| 건물 카드 | 마을에서 건물 탭 | 직종명·인원·초당 수입·다음 팀 보너스까지 남은 인원, 개성 분신 슬롯 1칸, 그 직종 고용 바로가기 |
| 사건 카드 | 말풍선 분신 탭 | 한 번 탭 또는 2지선다 |
| 월급 명세서 | 월급날 | 직종별 보너스 항목 + 개그 공제 |
| 도시 확장 | 이삿짐 트럭 탭 | 얻는 것 크게, 초기화되는 것 작게, 도시 규칙 한 줄, 버튼 하나 |
| 마무리 카드 | 할 일이 바닥났을 때 | 결산 + 다음 월급날 예고(제안) |
| 설정·우편함 | 상단 아이콘 | 사운드, 큰 글씨, 알림 2종, 저장·클라우드 백업, 우편 보상 |

**화면 규칙:** 동시에 생긴 사건은 겹쳐 띄우지 않고 대기열로 하나씩 이어서 재생한다. 첫 세션은 홈에서 시작하고, 이후에는 마지막으로 본 화면에서 시작한다.

### 4.3 고민 3단계

유저가 3초 안에 "분신 늘려서 돈 버는 게임"이라고 말할 수 있어야 한다. 모든 결정에는 '그냥 눌러도 되는' 기본값이 있다.

| 단계 | 대상 | 할 일 | 기본값 |
|---|---|---|---|
| 0. 생각 없이 | 모든 유저 | 탭, 고용, 정산 수령 | 추천 고용 표시, 매니저 해금 후 자동 |
| 1. 약간의 고민 | 대부분 | 사건 카드 2지선다, 자격증 vs 분신, 도시 확장 시점 | 추천 표시, 어느 선택도 큰 손해 없음 |
| 2. 원하면 깊게 | 하드 유저 | 개성 분신 배치 조합, 숨은 조건 찾기, 도시별 효율 | 자동 추천 배치, 몰라도 진행 막힘 없음 |

**UX 규칙:** 결정 화면의 선택지는 3개 이하. 화면에는 다음 목표 하나만 크게. 텍스트 튜토리얼 대신 손가락 가이드 하나. 1·2단계를 건너뛰어도 끝까지 진행 가능해야 한다(완료 기준).

## 5. 아트·연출

**치비 2D 플랫**으로 그리고, 만화 컷만 낙서풍 터치로 대비를 준다. '같은 얼굴이 잔뜩'이라는 웃음이 썸네일 한 장으로 읽혀야 한다.

### 5.1 아트 원칙

1. **같은 얼굴:** 분신은 전부 본체와 같은 얼굴. 의상·소품만 바뀐다.
2. **원본과 복사본:** 본체는 크고 표정이 많고, 분신은 작고 단순하게. 홈에서 원본을 먼저 각인시킨다.
3. **본체의 표정:** 탭 = 일하는 표정, 월급날 = 환호, 피버 = 확성기.
4. **본체의 자리:** 출세 단계에 따라 홈 배경이 바뀐다(반지하 → 편의점 카운터 → 사무실 책상 → 사장실 → 펜트하우스).
5. **도시별 직종 그림:** 도시 8개·직종 58종(R-011). 같은 칸은 건물 실루엣·동작을 공유하고 도시 의상·소품만 바꿔 부담을 줄인다. 창문 너머 잠긴 구역 미리보기는 그 도시 꼭대기 건물.
6. **직종 색:** 마을 구역 색 = 직종 색 = 고용 시트 색 = 도감 색.
7. **시간대:** 마을은 기기 시각에 따라 아침 출근 행렬, 밤 야근 불빛. 사진 모드에서는 시간대를 고를 수 있다.
8. **인파:** 멀리 있는 분신은 단순 실루엣으로 묶고, 동시 점프처럼 맞춘 동작으로 '귀여운 무리'를 만든다. 얼굴은 홈·건물 카드에서만. 구역마다 인파 밀도에 상한.
9. **품질 리스크:** AI 이미지로 변형을 만들 때 같은 얼굴이 유지되는지가 가장 큰 위험. 검수 체크리스트로 관리.

### 5.2 분신·본체·마을 디자인

언덕 아래 골목에서 꼭대기 주택가로 올라가는 세로 마을이 곧 출세 사다리다. 건물은 앞면이 반쯤 열린 단면(컷어웨이)이라 안에서 일하는 분신이 보인다.

| 직종 | 분신 의상·소품 | 마을 구역(아래 → 위) | 월급 명세서 항목 |
|---|---|---|---|
| 알바 | 편의점 조끼, 배달 헬멧, 카페 앞치마 | 언덕 아래 골목 | 주휴수당 |
| 직장 | 셔츠·넥타이, 사원증 | 중턱 오피스 거리 | 월급 상여 |
| 사업 | 사장 명찰 → 정장 | 상가 거리 | 결산 보너스 |
| 투자(증권사·건물) | 선글라스, 수트, 신문 | 꼭대기 고급 주택가 | 운용 수익 |

위 표는 우리 동네 기준이다. 도시별 의상·구역 표는 업무 보드 #10에서 작성 예정.

| 대상 | 디자인 |
|---|---|
| 본체 | 화면 가운데 크게, 표정 3종 이상, 출세 단계별 배경 5종 |
| 개성 분신 | 같은 얼굴 + 특징 소품(야근왕: 다크서클·커피, 지각왕: 토스트 물고 뛰기, 확성기 분신 등) |
| 기념 분신 | 100번째·1000번째 분신은 왕관 |
| 매니저 분신 | 클립보드 든 분신(제안, 미확정) |
| 도시 | 동네 → 서울 → 해외 대도시 패러디. 도시마다 빌딩 외관과 배경 교체 |

손맛(주스)은 규칙 추가보다 싸고 효과가 크다. 아래 연출마다 아트·연출부가 **초 단위 타이밍표**를 만들고 개발부가 그대로 구현한다. **타이밍표는 모두 작성 전이다.**

## 7. BM

확률 없이 '시간', '편의', '꾸미기'를 판다. 결제하지 않아도 모든 직종과 도시에 도달할 수 있고, 결제는 속도와 편의만 바꾼다. **가격과 수익 비중은 미정이다.**

**원칙**

1. 모든 유료 상품은 내용이 확정된 직접 구매. 확률 없음.
2. 핵심 진행(직종·도시 해금)은 무과금으로 도달 가능.
3. 광고는 유저가 골라 보는 보상형만. 강제 전면 광고 없음.
4. 광고 제안 위치는 정산서 1곳 + 상점만(피버·사건 카드에는 없음).

| 상품 | 내용 | 대상 | 상태 |
|---|---|---|---|
| 보상형 광고 | 오프라인 수익 2배(정산서), 잠깐 수입 부스트(상점). 일일 상한 + 쿨타임 | 무과금 | 채택 |
| 광고 제거 패키지 | 광고 없이 즉시 보상 + 상시 수입 부스트. 효과를 숫자로 표기 | 라이트 과금 | 채택 |
| 스타터팩 | 첫 구매용 저가 팩: 재화 + 개성 분신 1종(외형 위주, 효과 약하게) + 매니저 분신 즉시 해금 | 첫 결제 | 채택 |
| 시간 가속권 | 즉시 몇 시간분 수입. 무료 획득 경로 병행 | 전체 | 채택 |
| 매니저 조기 해금 | 무료 해금(월급날 4회) 전에 바로 | 전체 | 채택(스타터팩에 포함) |
| 코스메틱 | 본체·분신 의상, 마을·빌딩 외관. 효과 없음 | 수집형 | 채택 |
| 시즌 패스 | 월간, 무료·유료 트랙 | 중과금 | 출시 후 도입 |

## 10. 부서와 업무

### 10.1 일하는 방식

- 1인 개발 + AI 체제. 7개 부서를 '역할'로 둔다: 기획부 · 개발부 · 아트·연출부 · 콘텐츠부 · QA·데이터부 · BM·라이브부 · 마케팅부. 시스템 담당은 기획부 소속이지만 별도 대화로 운영 중(분리 여부는 미결정).
- **AI는 사용자가 지시한 업무만 한다.** 스스로 다음 일을 시작하지 않고, 작업을 마칠 때마다 '다음에 하면 좋을 일'을 이유와 함께 조언한다.
- **사용자가 결정하는 것:** 핵심 기획(규칙·재미 기둥·화면 구조), 아트 방향, BM 상품·가격·광고 위치, 일정, 비용, 출시·테스트 시작.
- **부서가 정하는 것(승인된 범위 안에서):** 페이싱 목표 범위 안의 수치 튜닝, 리소스·연출 세부, 문구(톤 가이드 안), 구현 방식, 작업 순서. 범위를 벗어나면 채팅에서 먼저 제안한다.
- **수정 절차:** 제안과 결정은 채팅에서 한다. 사용자가 채팅에서 '확정'하면 Claude가 아티팩트의 수정 요청 탭 기록 → 본문 → 결정 기록 → 버전을 고치고 '섹션 번호: 변경 요약'을 1~2줄로 보고한다.
- **이 파일의 동기화:** 기획서를 고쳐도 Claude Code용 파일은 사용자가 요청할 때만 아티팩트 최신 버전에 맞춰 고친다.
