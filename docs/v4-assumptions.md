## 3. 설계 판단

1. **배수 원천 6개 고정**(자리·레벨·적성·시설·자산·명성): 원천 안은 더하고 원천끼리만 곱한다. [기획 5.5]
2. **시설을 끝까지 키워도 승진이 항상 이득**: 시설 최고 × 자산 보너스 < 칸 사이 배율. 테스트 `Promotion_Is_Always_A_Raise...`로 고정. [가정] (첫 시안에서 시설 +10%×30단계가 승진보다 커서 승진이 멈추는 문제를 봇이 찾음)
3. **훈련비는 전체 수입에 비례**: 수입이 커져도 훈련으로 사다리를 건너뛰지 못하게. [가정]
4. **매니저는 자산을 사지 않는다**: 자동 고용·훈련·승진·시설만. 자산 선택은 플레이어의 고민으로 남긴다. [가정, 기획 4.6의 해석]
5. **'월세날'은 월급날에 합쳤다**: 새 타이머를 늘리지 않는다. [기획 4.4]
6. **도시 규칙 8종** 구현: 관광 시즌, 상장 우대, IP 로열티, 무역 입항, 개발 붐, 엔젤 배당, 지주회사. [기획 7.2를 단순화]
7. **이름 짓기**는 규칙만 있고 화면은 없다(입력창 UI 미구현).
8. **탭 해금**: 홈(처음) → 마을(첫 일터 5칸) → 분신(마을과 함께) → 상점(첫 월급날) → 자산(은행 예금). [기획 7.3]

## 5. 알려진 위험과 다음 확인

- **H2(노동→자본 전환) 체감이 약할 수 있다.** 봇 기준 자산 수입(월세·이자·배당)은 전체 수입의 1~2%. 자산의 실제 가치는 대부분 '입점 보너스·주식 보너스'(배수)로 나온다. 플레이 테스트에서 "월세가 들어오는 짜릿함"이 없으면 부동산 가격을 도시 꼭대기 수입에 묶어 월세 비중을 키우는 안을 검토.
- **봇은 사건 카드를 보지 못했다**(계속 탭하므로 무반응 12초가 오지 않음). 사람 플레이에서 확인.
- 첫 이사가 미드 유저 기준 1일 차로 기획 목표(3~4일)보다 빠르다. 꼭대기 승진비·신분 기준을 올리면 늦출 수 있다.
- 광고·결제는 가짜 구현이다. 출시 빌드에서 가짜 결제는 실패로 답한다(무료 지급 방지).
