# 디자인 기획 메모 — 분신 다양성 (피드백 b, PoC 미반영)

> 사용자 지시: 디자인·이미지 관련 내용은 나중에 판단한다. **PoC 그래픽은 바꾸지 않고** 기획 메모로만 남긴다. 기획서 §5(아트·연출)와 업무 보드 #10·#11의 입력 자료.

## 1. 원칙: '같은 얼굴'은 지키고, 나머지로 다양성

- 기획서 §5.1 원칙 1(같은 얼굴)과 충돌하지 않게, **얼굴 이목구비는 모두 같다**. 다양성은 아래 4가지에서만 만든다: 직종 옷 · 머리 모양 · 움직임 · 상호작용.
- 목표: 썸네일 한 장으로 '같은 얼굴이 잔뜩' + '각자 조금씩 다르게 산다'가 동시에 읽힐 것.

## 2. 직종별 옷(우리 동네 기준, 다른 도시는 소품만 교체)

| 직종 | 옷 | 소품 | 색(직종 색과 일치) |
|---|---|---|---|
| 편의점 알바 | 줄무늬 조끼 | 바코드 스캐너 | 하늘색 |
| 배달 라이더 | 헬멧 + 바람막이 | 배달 가방 | 하늘색(진함) |
| 카페 알바 | 앞치마 | 머그컵 | 하늘색(밝음) |
| 중소기업 사원 | 셔츠 + 넥타이 | 사원증 | 연두 |
| 분식집 사장 | 앞치마 + 사장 명찰 | 떡볶이 국자 | 노랑 |
| 투자 직종(도시 3~) | 수트 + 선글라스 | 신문 | 보라 |

## 3. 머리 모양: '어느 정도만' 다양

- 같은 얼굴 위에 **앞머리 6종**: 기본 · 가르마 · 곱슬 · 짧은 머리 · 묶은 머리 · 모자.
- 분신 번호로 결정(무작위 아님): `번호 % 6`. 같은 번호는 항상 같은 머리 → 애착('저 곱슬 #12').
- 비율은 기본 40%, 나머지 5종 12%씩 → 대부분 비슷하고 가끔 다름.
- 개성 분신은 머리 대신 특징 소품(야근왕: 다크서클·커피 등)으로 구분.

## 4. 움직임: 조금씩 다르게

| 요소 | 규칙 |
|---|---|
| 걷는 속도 | 기본 ±15%(번호로 고정) |
| 뒤뚱 박자 | 0.14~0.2초 |
| 대기 동작 | 3종 중 하나: 기지개 · 두리번 · 폰 보기(번호로 고정, 가끔 바뀜) |
| 출퇴근 | 아침(6~10시) 출근 행렬, 저녁 퇴근 행렬(시간대와 연동) |

## 5. 간단한 상호작용(2명 이상)

| 상호작용 | 조건 | 연출 |
|---|---|---|
| 인사 | 두 분신이 가까이 지나갈 때 | 서로 손 흔들기 + "어? 나네" 말풍선(가끔) |
| 하이파이브 | 같은 직종 두 명 | 손뼉 이펙트 |
| 같이 걷기 | 출근 시 | 2~3명이 줄지어 걸음 |
| 수다 | 대기 중 | 마주 보고 말풍선 '…' |
| 단체 리액션 | 월급날·팀 보너스 | 전원 동시 점프(이미 PoC에 있음) |

- 대사·상호작용 문구는 콘텐츠 CSV(`lines.csv` kind=interact)로 늘린다.
- 성능: 홈은 최대 15명이라 개별 상호작용 가능. 마을은 점 묶음 유지, 확대했을 때만 개별 표현.

## 6. 단체 사진(나중에 판단)

- 팀 보너스 사진의 포즈·배경 템플릿, 사진첩 꾸미기는 이미지 제작 방식이 정해진 뒤 결정(기획서 §11.1 '사운드·이미지 생성 도구 미정').
